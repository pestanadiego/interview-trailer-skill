# interview-trailer

Turn a long interview or video-call recording into a finished, subtitled mini-trailer from one prompt.

> "Make a 3-minute trailer from `webinar.mp4`. Include: what the product does, how it started,
> its three main features and the pricing. Don't mention competitors."

## Install

```bash
npx skills add pestanadiego/interview-trailer-skill
```

The only prerequisite is Python 3.8+ on the machine.
